# 04 — خطة التنفيذ على مراحل (Roadmap)

القاعدة: **كل مرحلة تنتهي بحاجة تشتغل على الشاشة وتُقاس.** مفيش مرحلة "بنية تحتية" لوحدها.

---

## M0 — الهيكل + وضع المُحاكاة (بدون أي موديلات) — ⏱️ يوم
**الهدف:** أقدر أشغّل البرنامج، أسحب فيديو، وأشوف ترجمة وهمية بتتحرك مع الوقت.

- [ ] `pyproject.toml` + بيئة Python 3.12 + ruff + pytest
- [ ] `core/models.py` (Segment, Context, Profile)
- [ ] `asr/mock.py` — بيولّد نص وهمي كل N ثانية
- [ ] `mt/mock.py` — بيقلب النص لـ "ترجمة تجريبية: ..."
- [ ] `ui/main_window.py` + drag&drop
- [ ] `player.py` — تضمين mpv (تشغيل/إيقاف/قفز/سرعة)
- [ ] `subs/renderer.py` — أوفرلاي عربي RTL بخط مضمّن + حد + ظل
- [ ] `engine.py` — يربط: audio → mock ASR → mock MT → composer → renderer
- [ ] قاعدة "السطر المعروض لا يتغير"

✅ **DoD (تعريف الانتهاء):** أسحب فيديو → يشتغل → ترجمة تظهر وتختفي في توقيتها → الأوفرلاي RTL مظبوط → العرض ميقطعش.
💡 **ليه نبدأ هنا؟** لأن Codex يقدر يبني ده بالكامل ويتأكد منه بمقاطع فيديو تجريبية، من غير ما نستنى تحميل ٦ جيجا موديلات.

---

## M1 — خط أنابيب حقيقي بملف (Offline / Pre-pass) — ⏱️ ٢-٣ أيام
**الهدف:** أول ترجمة حقيقية، أوفلاين، على فيديو كامل.

- [ ] `audio/file_source.py` (ffmpeg → 16k mono PCM، غير مقيد بالزمن)
- [ ] `audio/vad.py` (Silero v5)
- [ ] `asr/faster_whisper.py` (large-v3-turbo, CTranslate2, int8) + word timestamps
- [ ] `mt/nllb.py` (CTranslate2، `arb_Arab` + `arz_Arab`) — سريع على CPU/GPU
- [ ] `subs/composer.py` + `subs/arabic.py` (تقطيع ٤٢ حرف، منع الكسر السيئ، CPS)
- [ ] `core/cache.py` (SQLite) + مفتاح hash
- [ ] `workers/prepass.py` — يعالج الملف كله بأقصى سرعة مع progress
- [ ] تصدير SRT / VTT / TXT

✅ **DoD:** فيديو ١٠ دقائق إنجليزي → ملف SRT عربي صحيح، في أقل من ٣ دقائق، والترجمة متزامنة.

---

## M2 — السحر: الترجمة المتدرّجة أثناء التشغيل — ⏱️ ٢-٣ أيام
**الهدف:** الـ inversion — الفيديو يشتغل فورًا والترجمة تتحسن قدامك.

- [ ] `core/scheduler.py` — الـ ٣ tiers (draft/solid/refined) + تعقّب الـ playhead
- [ ] تأخير التشغيل القابل للضبط (`comfort buffer` ٣-٥ث)
- [ ] `asr/whisper_streaming.py` (LocalAgreement) للـ draft الحي
- [ ] دمج الـ pre-pass مع التشغيل: يسبق الـ playhead → يبدّل الـ draft بـ solid عند حدود الجمل فقط
- [ ] التعامل مع: seek / pause / speed change / seek أثناء المعالجة
- [ ] مؤشر بصري خفيف لحالة الجودة (نقطة صغيرة: رمادي=مسودة، أبيض=ثابت)

✅ **DoD:** أضغط Play → ترجمة خلال <٢ث → بعد ~٣٠ث تصبح ثابتة وأدق → صفر رفرفة → القفز للأمام/للخلف سليم.

---

## M3 — جودة الترجمة: السياق + المصري — ⏱️ ٣-٤ أيام
**الهدف:** الفرق بين "ترجمة آلة" و"ترجمة بتحسها مكتوبة بإيد".

- [ ] `mt/llm_translator.py` (llama.cpp server: Vulkan/CUDA/CPU)
- [ ] تحميل موديلات تلقائي حسب بروفايل الجهاز + شريط تقدم
- [ ] `prompts/msa.j2` + `prompts/egyptian.j2` (few-shot أمثلة حقيقية)
- [ ] `mt/glossary.py` — استخراج أسماء/مصطلحات من أول دقيقتين + التزام بها
- [ ] تصنيف المجال (domain) التلقائي
- [ ] `mt/dialect_linter.py` — قواعد كشف الفصحى + إعادة صياغة
- [ ] ترجمة دفعية (batching) للسرعة
- [ ] `workers/refine.py` — pass تحسين للقطع غير المعروضة
- [ ] مقياس جودة: `tools/benchmark.py` على عينة (BLEU/COMET + latency)

✅ **DoD:** على عينة ٣٠ دقيقة en→ar، تقييم بشري يوضّح تحسّن واضح عن M1. المصري "مقبول وطبيعي".

---

## M4 — "ترجم كل حاجة" + التلميع — ⏱️ ٢-٣ أيام
- [ ] `audio/loopback_source.py` (WASAPI) + اختيار جهاز الصوت
- [ ] وضع fullscreen overlay مستقل عن المشغّل (يعمل فوق YouTube/Netflix)
- [ ] إعدادات كاملة (خط، حجم، لون، خلفية، موضع، تأخير يدوي)
- [ ] النظام في Tray + تشغيل تلقائي اختياري
- [ ] اختصارات: تبديل لهجة، إظهار الأصل، "السطر الأخير تاني" (Rewind ٥ث)
- [ ] `tools/build_portable.py` → ZIP محمول + installer

✅ **DoD:** أشغّل يوتيوب في المتصفح → الترجمة العربية تظهر فوقه. والبرنامج يتوزّع كملف واحد.

---

## M5 — الدبلجة الصوتية (اختياري / مرحلة متقدمة)
- [ ] TTS عربي ستريمنج (Qwen3-TTS Apache-2.0 — نتأكد من دعم العربية محلياً؛ أو Voxtral TTS بعد مراجعة الترخيص)
- [ ] خفض صوت الأصل لـ ١٥-٢٥٪ + تشغيل الصوت العربي متزامناً
- [ ] استنساخ صوت المتكلم (٣ ثواني عيّنة) — اختياري
- [ ] مطابقة الطول الزمني للجملة الأصلية (duration-aware TTS)

---

## M6 — الخندق التنافسي (Moat)
- [ ] Fine-tune موديل مصري صغير على [ArzEn-MultiGenre](https://arxiv.org/pdf/2508.01411) (٢٥ألف زوج) + بيانات مولّدة
- [ ] بحث فوري في الفيديو بالعربي + "اسأل الفيديو" / تلخيص
- [ ] كاش مجتمعي اختياري (opt-in) — ملفات الترجمة للمحتوى الشائع
- [ ] حزم لهجات: مصري / شامي / خليجي / مغربي
