`Segment` يفرض قراره على مستوى **اللغة نفسها** لا على مستوى الاصطلاح:
```python
def __setattr__(self, name, value):
    if name in _FROZEN_AFTER_DISPLAY and getattr(self, "displayed", False):
        raise ImmutableCueError(...)
```
حارسٌ يُنسى ويُنسى. أما `__setattr__` فيُطبَّق حتى على كود لم يقرأ الوثيقة.

## ٣) انبثاق الصلابة — القياسات الفعلية

### 🔬 البرهان ١: `Δ` يشتري جودة الدقائق الأولى (مُقاس، لا مُدَّعى)
```
 Δ (ثانية) │ جودة أول سطر │ جودة آخر سطر │ المتوسط
       0.0 │        0.000 │        0.984 │   0.855   ← الأولى **لا تظهر أصلاً**
       0.5 │        0.663 │        0.984 │   0.939
       1.0 │        0.774 │        0.984 │   0.953
       2.0 │        0.898 │        0.984 │   0.969
       4.0 │        0.980 │        0.984 │   0.979
       8.0 │        0.999 │        0.984 │   0.981
```
**الاكتشاف:** عند Δ=٠ **جودة أول سطر = ٠.٠٠٠** — أي أنه لا يظهر إطلاقاً.
هذا ليس عيباً في النموذج، بل **حقيقة رياضية**: `ميزانية القطعة = (a_i + Δ) · throughput`
فإن كان `a₁ ≈ 0` و`Δ = 0` فالميزانية = صفر.

⇒ **`Δ` ليس معلمة ضبط (tuning knob) بل متغيّر تصميم أساسي.**
⇒ `Δ*(٨٠٪) = ١.١٧ث` · `Δ*(٩٥٪) = ٢.٩ث` — مشتقّتان لا مختارتان.

### 🔬 البرهان ٢: التقطيع العربي يحترم الترابط
```
الأصل (41 حرف): سافر أحمد إلى القاهرة أمس لحضور مؤتمر مهم
  [1] سافر أحمد إلى القاهرة        (21 حرف)
  [2] أمس لحضور مؤتمر مهم          (19 حرف)
```
الكسر **تجنّب** «إلى» من الجهتين. ولو استخدمنا `textwrap` لانتهى السطر الأول
عند «إلى» أو بدأ الثاني بها — خطأ يراه كل عربي في لمحة.

### 🔬 البرهان ٣: صفر رفرفة — الرابطة التي لا يملكها مكوّن
```
١) مسوّدة أولية          : applied
٢) ترقية قبل العرض       : applied
٣) تنزيل مرفوض           : rejected:downgrade
٤) بعد العرض: تحسين أفضل : rejected:displayed      ← حتى الأفضل يُرفض
٥) تغيير مباشر للمتغيّر   : ImmutableCueError       ← على مستوى اللغة
النص النهائي: هارجع تاني  (لم يتغيّر)
```

### 🔬 البرهان ٤: اتساق الكيانات
```
بلا قاموس : معدل الاتساق =   0%     (John → جون / جوان · Acme → أكمي / أكمة)
بالقاموس  : معدل الاتساق = 100%
```
### 🔬 البرهان ٥: محور السجل متصل
```
فصحى متسللة: هل تود أن تذهب إلى المدرسة الآن؟        → سجل 0.00
بعد المصلِح : هل تود أن تذهب إلى المدرسة دلوقتي؟      → (كشف ٣ تسلّلات)
مصري أصيل  : إنت عايز تروح المدرسة دلوقتي؟           → سجل 1.00
```

### 🔬 البرهان ٦: تشغيل كامل — Δ* محسوبة، طبقات مرتّبة، رفض بعد العرض
```
Δ* المحسوبة = 2.02 ثانية (الهدف: جودة ≥ ٨٥٪)
      s0 │   2.02ث │ 0.620 → 0.851 │ ↗ ثابت
      s3 │  13.02ث │ 0.620 → 0.976 │ ↗ محسّن
    ⏱  13.5ث  ظهر: الحديد ناعم والكربون / هش بس مع بعض يبقوا صلب
محاولة تحسين السطر الأول بعد عرضه → rejected:displayed
```

## ٤) الرياضيات (كما نُفِّذت في `core/scheduler.py`)

```
المهمة i:  r_i = 0            (ملف محلي)
           d_i = a_i + Δ      (الموعد = بداية النطق + تأخير الراحة)
           m_i                (إلزامي: مسوّدة)
           κ_i                (الصعوبة: طول + ندرة + استفهام)

الجودة:    Q_i(c) = 0                                              إن c < m_i
                  = q₀ + (q∞ − q₀)·(1 − e^{−κ_i·(c−m_i)})            خلاف ذلك

المسألة:   maximize Σ Q_i(c_i)  s.t.  Σ_{j: d_j ≤ t} c_j ≤ C(t)  ∀t

الخوارزمية (DQC):
   ١. مهمة إلزامية؟  → EDF (الأقرب موعداً أولاً)     [الكسب الحدّي = ∞]
   ٢. وإلا           → أعلى dQ/dc بين من لم يفت موعدها  [water-filling]
   ٣. فات الموعد؟    → تجميد نهائي (لا حساب بعد العرض)

الجدولية:  ∀i بترتيب EDF:  Σ_{j≤i} m_j ≤ d_i · throughput · utilization
           الفشل ⇒ تعطيل الستريمنج ⇒ pre-pass فقط.  (قرار آلي لا بشري)
```

## ٧) ما كشفه الاختبار قبل أن يكشفه المستخدم (٣ أخطاء حقيقية)

| # | الخطأ | كيف كُشف | القرار المتخذ |
|---|---|---|---|
| ١ | `split_lines` كان **يحذف التشكيل** أثناء التخطيط | اختبار مقارنة الكلمات | فصلنا: **نقيس بلا تشكيل، ونُخرج النص كما ورد**. التطبيع خطوة صريحة في `Composer.compose()` |
| ٢ | الكسر قد يقع عند حرف جرّ («إلى/في/من…») | اختبار قاعدة الأدوات الملتصقة | وسّعنا `PROCLITICS` بحروف الجرّ لا حروف العطف فقط |
| ٣ | اختبار الجدولية يُحسب بـ Δ=٠ وهو مستحيل بديهياً | العرض | صار يُحسب **بعد** تطبيق `Δ*` |

> القيمة الحقيقية للاختبارات هنا ليست «منع الأخطاء» بل **إجبار الروابط على
> إظهار نفسها**. اختبار يمرّ بلا أن يمسّ رابطة = اختبار بلا فائدة.

## ٨) القيود — بصراحة

1. **لا موديلات بعد.** كل المنطق حقيقي، وكل الترجمات في العرض **مكتوبة يدوياً**
   لإثبات الشبكة. ASR/MT تأتي في M1–M3 خلف واجهات `Protocol`.
2. **الثوابت ⚠️ تحتاج معايرة** على بيانات حقيقية قبل أن تُعتمد أرقاماً.
3. **واجهة المستخدم غير موجودة** — لا PySide6 ولا mpv بعد (M0).
4. `κ` (الصعوبة) تقدير بدائي: **الترتيب النسبي** يكفي water-filling،
   لكن دقته المطلقة لم تُقَيَّم.
5. **لم يُختبر على فيديو حقيقي** — العرض يستخدم نصوصاً مُعَدّة.
6. المحاكاة تفترض `throughput` ثابتاً، بينما الواقع متذبذب (تسخين GPU، تطبيقات أخرى).

## ١٠) الجملة الأخيرة

**الصلابة في الفولاذ ليست في الحديد ولا في الكربون.**
وكذلك الجودة في «فوري»: ليست في الموديل الأكبر، ولا في الواجهة الأجمل،
ولا في الموديل العربي الأفضل — بل في **شبكة الروابط** التي تجعل كل هذه
تعمل كجسد واحد: قطعة تعرف موعدها، وموعد يعرف جودته،وجودة تحترم أن السطر
إن ظهر فقد صار أثراً لا يُمحى.
