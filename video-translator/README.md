# 🎬 فوري — Fawri

> **ترجمة فورية لكل اللي بتتفرج عليه — على جهازك، بدون إنترنت، بدون خطوة واحدة.**

---

## الفكرة في سطرين

كل أداة ترجمة موجودة بتتعامل مع الفيديو كأنه **بث مباشر**، فبتحارب زمن التأخير
وبتطلع ترجمة بترفرف وقدامك النص بيتغير.

لكن **الفيديو المحلي موجود كله من أول ثانية**، وصوته يتفك أسرع من التشغيل بـ ٨–٣٥ مرة.
فبدل ما نستنى الترجمة… **نخلي الترجمة هي اللي تستنى المشاهد.**

→ المستخدم يضغط Play: ترجمة خلال أقل من ثانيتين، وبعد ٣٠ ثانية بتبقى نسخة أدق وثابتة،
بدون **أي** سطر يتغير بعد ما اتعرض.

## المكدس التقني (مختصر)

```
PySide6 (Qt6/HarfBuzz للعربي)  +  libmpv للتشغيل  +  ffmpeg للأوديو
ASR : Qwen3-ASR (ستريمنج+أوفلاين، 52 لغة)  /  faster-whisper turbo
MT  : Qwen3-4B عبر llama.cpp (Vulkan/CUDA/CPU)  +  NLLB-1.3B (فيه arz_Arab للمصري)
VAD : Silero v5   │   كاش: SQLite   │   منصة أولى: Windows 10/11
```
