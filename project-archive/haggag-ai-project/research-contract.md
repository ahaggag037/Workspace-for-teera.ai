# Research Contract & Continuity

## Global objective
Study the full problem space around building highly reliable AI-agent systems and test whether a reusable model-independent cognitive/operational layer can measurably improve different compatible models. Target qualities: evidence-grounded work, long-horizon continuity, reliable state handling, auditability, safe tool use, recovery, and enterprise suitability.

## Active research boundary
- Discovery and learning only.
- Do not prematurely select a final architecture, stack, roadmap, or implementation plan.
- Prefer current primary sources, direct implementation evidence, standards, papers, original repositories, incident reports, and current product documentation.
- Community sources are signals about real-world behavior, not verified universal facts.
- Search deliberately for contrary evidence, failure cases, stale assumptions, and simpler explanations.
- Distinguish discovered, available, configured, authorized, tested, and verified.
- Never claim access to hidden model internals or private chain-of-thought.

## Continuity rule
Side questions, interruptions, and temporary detours are branches, not task revisions. After resolving a detour, resume from the nearest valid research state unless the user explicitly changes the global objective.

## Adaptive-methodology commitments
1. Reconstruct the global objective before consequential recommendations.
2. Separate verified evidence, user preferences, hypotheses, assumptions, decisions, corrections, and open questions.
3. When freshness can change the answer, verify with current sources before committing.
4. Apply methodological corrections during the same task rather than merely recording lessons for later.
5. Add an agent, role, protocol, integration, framework, or formalism only if it has concrete decision or execution value.
6. When a premise changes, invalidate dependent conclusions and recompute from the nearest sound point.
7. Persist consequential discoveries and open questions in external state when authorized and available.
8. Treat stored memory as state with provenance, not as truth.

## Research function
“The Greatest Researcher” was used only as a methodological function: triangulate primary, implementation, and community evidence; seek disconfirming evidence; state what a finding changes and what could falsify it. It is not an independently conscious or background agent.
