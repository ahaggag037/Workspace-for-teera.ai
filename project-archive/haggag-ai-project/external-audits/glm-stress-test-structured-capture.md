# GLM Stress-Test — Structured External Evidence

Status: **UNVERIFIED EXTERNAL MODEL OUTPUT**.

GLM was asked to stress-test Constitution v0 with concrete failure scenarios and research real-world analogues. This file preserves a structured capture of the report supplied in the project conversation; it is not a canonical evidence source.

## Main themes raised

- advisory instructions are insufficient for consequential tool actions;
- verifier/generator common-mode failure;
- multi-writer and stale state;
- supply-chain and untrusted-content risk;
- model/tool drift;
- multi-actor authority and accountability;
- graceful degradation;
- self-governance / evaluator changes;
- limits of codifying professional expertise;
- behavioral acceptance tests as a better target than role vocabulary.

## Verification caution

Several incident claims in the report rely on secondary blogs/forums. In particular, Amazon Kiro causation, Google Antigravity hard-drive deletion, and some MCP/agent incident details require independent verification before use in the Constitution.

## Merge rule

Do not merge any claim or proposed invariant into Constitution v1 until cross-model comparison and primary-source verification are complete.
